# HarpyOrder — منصة طلبات المطاعم المباشرة عبر الواتساب (WhatsApp Ordering)

نظام متكامل، سريع، وخفيف جداً لطلب الطعام والوجبات أونلاين عبر الواتساب مباشرة، مع دعم الدفع عند الاستلام ومحافظ الكاش الإلكترونية (فودافون كاش / إنستاباي).

---

## 🎯 مميزات المنصة
1. **واجهة الزبائن (Storefront - `index.html`)**:
   * تصفح الأصناف والأقسام بالصور والأسعار والوصف مع بحث فوري.
   * سلة مشتريات عائمة تتيح زيادة/إنقاص الكميات ومعاينة الإجمالي في الوقت الفعلي.
   * إتمام الطلب (الاسم، رقم الهاتف، العنوان بالتفصيل، وأي ملاحظات).
   * **طرق الدفع:**
     * **دفع نقدي عند الاستلام (COD):** يُرسل الطلب فوراً للمطعم.
     * **محفظة كاش (فودافون كاش / إنستاباي):** يظهر رقم المحفظة مع إمكانية نسخه بضغطة زر + إرفاق سكرين شوت التحويل.
   * **التحويل المباشر للواتساب:** يتم تجهيز رسالة احترافية منظمة كفاتورة بجميع التفاصيل وإرسالها مباشرة لشات الواتساب الخاص بالمطعم.

2. **لوحة تحكم المطعم (Admin Panel - `admin.html`)**:
   * محمية برمز مرور (PIN) قابل للتغيير (الافتراضي: `1234`).
   * إضافة / تعديل / حذف الأصناف وتحديد الأسعار والصور.
   * إضافة وإدارة الأقسام والتصنيفات.
   * ضبط إعدادات المتجر: اسم المطعم، رقم الواتساب، رقم محفظة الكاش، العملة، الشعار والغلاف.

---

## 🚀 كيفية التشغيل والرفع
* **التشغيل المحلي:** افتح ملف `index.html` في المتصفح مباشرة.
* **الرفع على GitHub Pages:** ارفع محتويات المجلد `order` إلى مستودعك ليعمل الرابط فوراً دون الحاجة لأي خوادم أو تثبيت برامج!
