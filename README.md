# 🦅 Harpy Order — Smart Restaurant Delivery Menu & Dashboard

منصة متطورة وذكية لطلبات الدليفري والأونلاين للمطاعم والكافيهات، تدعم تعدد المطاعم وحساب الإضافات والأحجام والخصومات المتعددة وإرسال الأوردرات المنسقة صوتياً وحسابياً عبر الواتساب بدون عمولات.

## ✨ المميزات الرئيسية:
- 📱 **واجهة مستخدم عصرية وسريعة (PWA)**: تجربة مستخدم فائقة السلاسة تعمل على الموبايل والتابلت والكمبيوتر.
- 🍔 **تخصيص متقدم للوجبات**: دعم الأحجام، الأوزان، والإضافات المدفوعة، والملاحظات الخاصة.
- ⚡ **خصومات ذكية ثلاثية**:
  - خصم الدفع الإلكتروني عبر المحافظ (فودافون كاش / إنستاباي) مع إمكانية إرفاق صورة التحويل.
  - خصم الطلب المميز تلقائياً عند تخطي حد أدنى للفاتورة.
  - نظام كوبونات الخصم الترويجي (Promo Codes).
- 🎨 **منظومة ألوان وثيمات راقية**: وضع نهاري كلاسيكي فاخر (Luxury Cream)، وضع ليلي فاحم مريح للعين (Warm Charcoal)، مع 7 قوالب لونية جاهزة للمطاعم.
- 🏢 **نظام تعدد المطاعم (Multi-Tenant Architecture)**: كل مطعم يمتلك رابطه المستقل (`?m=restaurant-name`) مع لوحة تحكم مستقلة وخاصة.
- 🛡️ **نظام اشتراكات سحابي متصل بـ Firebase وتليجرام**: فحص لحظي ومباشر لحالة التراخيص والاشتراكات.
- 💬 **إرسال الطلبات إلى واتساب**: توليد رسالة واتساب مفصلة ومحسوبة بالمليم بضغطة زر واحدة.

## 🚀 الملفات الأساسية:
- `index.html`: واجهة المنيو للزبائن.
- `admin.html`: لوحة تحكم صاحب المطعم.
- `css/style.css`: ملف التنسيقات والألوان المتجاوبة.
- `js/store.js`: محرك إدارة البيانات والسلة والاشتراكات.
- `js/app.js`: منطق تشغيل المنيو والزبائن.
- `js/admin.js`: منطق لوحة الأدمن وإدارة الأصناف.
- `manifest.json` & `sw.js`: دعم العمل كتطبيق هاتف وتخزين الكاش.
